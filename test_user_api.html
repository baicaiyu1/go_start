校验规则说明

name    : 必填，2~20 个字符
age     : 必填，0~130
email   : 必填，合法邮箱
role    : 可省略（默认 user），只能是 admin / user
tags    : 最多 5 个，每个至少 1 个字符

成功：201 {"data":{...}}
校验失败：422 {"code":422,"message":"参数校验失败","fields":{"字段":"规则"}}
格式错误：400 {"code":400,"message":"参数格式错误"}
打不开或报 Failed to fetch？ 依次检查：1) 服务是否已启动；2) 地址端口是否为 8080； 3) 服务端需返回 CORS 头（本项目已在 biz/middleware 里开启）。
说明：页面用 fetch 直接把 JSON 发给 Hertz，展示状态码、耗时和原始响应体。
